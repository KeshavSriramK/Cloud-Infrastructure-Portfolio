# ⚔️ Uptime Viking: HTTPS-Secured Game Server & Serverless Discord Telemetry

An automated Infrastructure-as-Code (IaC) project provisioning a Dockerized game server behind an Nginx reverse proxy with automated Let's Encrypt SSL/TLS certificates (HTTPS) and real-time Discord telemetry via AWS SSM.

terraform init
terraform apply
